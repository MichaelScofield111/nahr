## What It Does

Given one input video, the pipeline does:

1. Extract audio to WAV (`16kHz`, `mono`, `16-bit PCM`)
2. Run Whisper ASR to generate source-language subtitles (`.srt`)
3. Translate subtitle text into Simplified Chinese
4. Burn Chinese subtitles into a new MP4
5. Remove temporary files by default (unless `--keep-temp` is set)

The output file name is:

- `<input_stem>_cn_bake.mp4`

Example:

- `example.mp4` -> `example_cn_bake.mp4`

## Requirements

You must install these system dependencies before running:

- `ffmpeg` (CLI executable)
- `libass` support enabled in your FFmpeg build (required by FFmpeg `subtitles` filter)

### Verify FFmpeg and libass

```bash
ffmpeg -version
ffmpeg -filters | grep subtitles
```

If the `subtitles` filter is missing, your FFmpeg build likely does not include `libass`.

## Project Setup

### 1. Clone and enter project

```bash
git clone
cd nahr
```

### 2. Prepare Whisper model

Put your Whisper model file at:

- `models/ggml-base.bin`

This path is the default value for `--whisper-model-path`.

## Build

```bash
cargo build --release
```

## Usage

### Basic usage (uses default model path)

```bash
cargo run --release -- \
  --input-file assets/example.mp4 \
  --language en
```

### Specify a custom model path

```bash
cargo run --release -- \
  --input-file assets/example.mp4 \
  --language en \
  --whisper-model-path /absolute/path/to/your/model.bin
```

### Keep intermediate files for debugging

By default, temporary files are removed after successful subtitle burn-in.
Use `--keep-temp` to keep generated `.wav` and `.srt` files.

```bash
cargo run --release -- \
  --input-file assets/example.mp4 \
  --language en \
  --keep-temp
```

## CLI Options

- `--input-file <FILE>`: Input MP4 video path (required)
- `--language <LANG>`: Source speech language (`en` default; translation currently supports `en` and `ja`)
- `--whisper-model-path <FILE>`: Whisper model path (default: `models/ggml-base.bin`)
- `--keep-temp`: Keep temporary WAV/SRT files (default: off)

## Important Notes

- `models/` should not be committed to GitHub in most cases.
  Large binary model files bloat repository size and slow cloning.
- This project already ignores `models/` in `.gitignore`.
- If you must version model files, use Git LFS.
- Translation quality depends on the source subtitles and model quality.
- Burning subtitles rewrites video output; keep your original source file as backup.

## Troubleshooting

### `ffmpeg failed to burn subtitles`

Possible reasons:

- FFmpeg is not installed
- FFmpeg does not include `libass`
- Subtitle path has permission/access issues

Check:

```bash
which ffmpeg
ffmpeg -filters | grep subtitles
```

### Model load failure

Check:

- Model file exists at `models/ggml-base.bin` (or your custom path)
- File is readable
- Model format is compatible with `whisper-rs`
